# ZERO DAY — Задачи, порядок и параллельность

Рабочий трекер задач по разделу 14 ТЗ. ТЗ остаётся источником истины по содержанию задач; этот файл — по статусу и порядку.

**Как пользоваться**

- Отметить готовую задачу: `- [ ]` → `- [x]` (готово = выполнен Definition of Done, раздел 13.4 ТЗ).
- Взятую в работу задачу пометить: `- [ ] **T-B3** … · в работе: <кто>`.
- Незаконченную задачу после каждой сессии дополнить строкой прогресса: `  - Прогресс: сделано …; осталось …`. При закрытии строку убрать.
- Формат строки: **ID** · задача · зона · оценка · приоритет · *после:* зависимости.
- Зоны: ENG — движок, WEB — клиент, API — backend, CNT — контент, INF — инфра, QA — тесты/презентация.
- Оценки: S ≤ полдня, M ≈ день, L ≈ 2–3 дня (с ИИ-ассистентом).

**Команда (4 человека, роли совмещены)**

| Дорожка | Кто | Зоны |
| --- | --- | --- |
| ENG | Техлид / FE-1 | packages/engine, content-tools, архитектурное ревью |
| WEB | FE-2 | apps/web: карта, терминал, головоломки, UI, аудио |
| BE | Backend / инфра | services/api, infra, CI/CD, VPS |

## 2. Последовательность выполнения

Задачи идут волнами. Внутри волны дорожки (ENG / WEB / BE / CNT) работают параллельно; задача стартует, когда закрыты её зависимости, не дожидаясь конца всей волны.

### Волна 0 — Каркас (M0). Все вместе

1. **T-A1** — один человек, остальные готовят окружение и читают ТЗ. Блокирует всё.
2. Параллельно сразу после T-A1:

| ENG | WEB | BE | CNT |
| --- | --- | --- | --- |
| T-A3 → T-A4 | T-A6 → T-A9 | T-A5, T-A2, T-A11 | T-G8, черновик T-D1 (тексты, без схемы) |

3. Затем BE: **T-A7** (после T-A5, T-A6) → **T-A8**, **T-A10**.

**Готово, когда:** docker compose up поднимает пустой экран с никнеймом; CI зелёный; сайт открывается по домену через HTTPS.

### Волна 1 — Вертикальный срез на «Соседе» (M1)

| ENG | WEB | BE | CNT |
| --- | --- | --- | --- |
| T-B1 → T-B3 → T-B2, T-B4 (параллельно) → T-B5 (сначала 01, 02) | T-C1 (после T-B3) → T-C2, T-C4, T-C6 (параллельно) → T-C5 (view 01, 02) | T-G1, T-E1 (задел), помощь ENG с T-B4 | T-D1 → T-D4 «Сосед», T-D3, T-D8 |

**Готово, когда:** «Сосед» проходится от брифа до закрытия: скан → гипотеза → «Колесо» → узел взят → тревога растёт → откат при 100.

| ENG | WEB | BE | CNT |
| --- | --- | --- | --- |

**Готово, когда:** «Сосед» → «Колледж» проходится на десктопе и телефоне без ошибок; солвер доказывает ≥ 2 пути.
